🧺 Laundry Wallah / Laundry Mart

A simple and responsive laundry service website built using HTML.

📖 Overview

Laundry Wallah / Laundry Mart is a static website designed to showcase professional laundry services, pricing details, and a basic booking form.
The project focuses on fundamental HTML structure, semantic elements, and clean content presentation.

✨ Features

✅ Business introduction section

✅ Services listing

✅ Pricing table

✅ Booking form (Name, Email, Phone)

✅ Contact information

✅ Clean and minimal layout

🛠 Tech Stack

HTML5

Basic Inline CSS
